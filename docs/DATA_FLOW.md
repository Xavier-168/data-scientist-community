# 数据流

## 核心流程

```text
用户选择平台和日期
  -> 本地 runner 创建任务与锁
  -> Playwright 打开用户可见授权/创作者页面
  -> 平台响应写入本地临时 JSON/官方导出
  -> normalizer 统一字段并过滤无效记录
  -> Excel + SQLite + 运行历史
  -> 可选：用户触发飞书同步
```

## 数据分类

| 类别 | 示例 | 默认位置 | 是否进入仓库 |
|---|---|---|---:|
| 登录态 | Cookie、Profile、授权标志 | 用户状态目录 `.auth/` | 否 |
| 作品数据 | 标题、发布时间、播放/阅读、链接 | 用户状态目录 `downloads/` | 否 |
| 配置 | 平台范围、日期、飞书凭据和表 ID | 用户状态目录 `.auth/` | 否 |
| 运行元数据 | 状态、错误、耗时、checkpoint | 用户状态目录中的日志/JSON/SQLite | 否 |
| 代码验证材料 | 公钥、锁文件、SBOM | 源码仓库 | 是 |
| 私钥/商业台账 | 包签名私钥、管理员密钥、客户记录 | 社区边界外 | 永不 |

## 平台流程

### 抖音

本地浏览器访问创作者内容管理页面，平台 Cookie 仅由浏览器发送给抖音域名；程序监听用户可访问的作品列表响应，按日期整理后写本机。

### 小红书

本地浏览器访问数据分析与作品管理页面。设置日期窗口时，发布日期不可解析的记录不默认放行，避免旧缓存混入。

### B站

先按日期查询目标稿件集，再按官方单批限制分批导出/校验。登录态只用于 B站站点和创作中心请求。

### 快手

本地浏览器访问创作者数据和作品页，记录用户可见的作品分析响应并写本机。

## Excel

四平台结果进入 `platform_source_rows.py` 的统一链路。播放量大于零直接保留；播放量为零时，小红书阅读量大于零仍保留；两者均为零才过滤。Excel 是用户本地文件，项目不会自动上传。

## 飞书

用户可选择 OpenAPI App 凭据或 Lark CLI 用户授权。同步准备脚本读取本地作品和 checkpoint，向用户指定的多维表格创建/更新字段和记录。App Secret 用于向飞书换取短期 Token，不应写日志或返回前端明文。Lark CLI 的 HOME、配置和大请求临时 JSON 均位于用户状态目录，不读取其他应用的凭据目录，也不写入源码目录。

## 删除与撤销

用户应先退出应用，再删除运行目录中的 Profile、导出、数据库和日志；同时在对应平台及飞书撤销授权。项目维护者无法删除保存在用户设备或用户第三方租户中的数据。
