# Community 与商业产品边界

## 许可不是功能收费开关

AGPL-3.0-only 允许个人、组织和商业使用。用户是否付费取决于其是否需要另一份闭源商业许可、社区仓库之外的私有能力或合同服务，不取决于“公司使用”这个身份标签。

## 文件级边界

### 社区公开

- macOS 本地壳、前端和 Python 编排；
- 四平台社区采集适配；
- 数据规范化、Excel、基础飞书同步和本地分析；
- 公钥与签名校验逻辑；
- 测试、源码 staging、SBOM 与公开文档。

### 商业/内部

- 激活服务端和生产配置；
- 私钥、管理员密钥、客户许可证和销售台账；
- 客户包生成器、runtime 打包和内部发布管线；
- MCN 多账号、团队权限、白标、OEM、托管和 SLA；
- Human State Intelligence 私有算法、研究数据与商业策略；
- 客户数据、Profile、日志、历史 DMG 和内部 Agent 文档。

## 能力矩阵

| 能力 | Community | 商业协议可选 |
|---|---:|---:|
| 单机四平台工作流 | 是 | 是 |
| Excel 和基础飞书同步 | 是 | 是 |
| 修改、研究、自部署 | AGPL 条件下 | 合同条件下 |
| 闭源嵌入/再分发 | 需遵守 AGPL | 是 |
| MCN 多账号/团队 | 否 | 是 |
| 白标/OEM/托管 | 否 | 是 |
| 定制、支持、SLA | 社区尽力 | 是 |
| HSI 私有能力/数据 | 否 | 另行评估 |

## 贡献与双重许可

为了能在未来同时维护 AGPL 与商业许可，外部贡献必须签署 CLA，向项目方授予再许可所需权利。DCO 只声明提交来源，不能单独解决商业再许可授权链。
