# v0.1.0-rc.1 发布说明

这是从商业开发仓库当前安全白名单导出的首个社区源码候选，使用全新 Git 历史。

## 2026-08-14 紧急修复说明

1. **同一作品没有跨平台合并**：Excel 分组与飞书分组的标题相似度阈值同步调整为 `0.40`。已用“如果你用不了 Codex…【Cherry-Studio 手把手教程】”与“小红书仅保留【Cherry-Studio 手把手教程】”的真实标题形态做回归，三平台会得到同一作品组 ID。
2. **B站长时间停在“准备启动”**：根因不是 B 站采集接口本身，而是两工作线程被前序平台已经完成但未退出的浏览器/调试器进程占用，同时所有平台过早显示为运行中。现在未获得线程的平台显示“排队等待”；进度文件明确完成或失败后，监督器会在 5 秒清理宽限后回收滞留进程组并释放槽位。
3. **原生客户端无法导出 Excel/打开飞书授权页**：后端下载端点和 Excel 文件本身正常，问题位于 Tauri WebView 的新窗口处理。客户端现在只允许飞书/Lark HTTPS 授权地址和本机 `/download-excel` 由系统浏览器接管，既恢复功能，也不放开任意外部网址。

## 包含

- 抖音、小红书、B站、快手四平台本地采集入口；
- 数据规范化、Excel、本地分析和基础飞书同步；
- Vanilla HTML 仪表盘与 Tauri/React 桌面壳源码；
- 默认每 6 小时对已授权平台做一次保守的登录态检查，并在本地仪表盘显示最近检查状态；
- AGPL、商业许可说明、CLA、隐私、安全、平台合规和第三方声明；
- 公开导出清单、脱敏扫描器、源码 staging 和 SPDX SBOM。

## 明确排除

客户数据与 Profile、生产服务配置、客户包生成器、发货台账、私钥运维、历史 DMG、来源无法证明的原字体、原品牌图标、内部 Agent 文档、MCN/团队/白标/OEM/托管/SLA 与 HSI 私有能力。后续 rc.2 仅新增可追溯并随附 OFL 1.1 的 Noto Serif SC 字体。

## 安装

参见根目录 README。当前只发布源码，不发布签名或公证的 DMG。

建议运行环境为 macOS 11+、Python 3.11+（已实测 3.12）、Node.js `>=22.12.0 <23` 与 Git。普通源码运行不需要 Rust；只有构建或测试 Tauri 桌面壳时才需要 Rust stable 和 Apple 平台构建环境。安装前应先执行 README 中的 Python 标准库预检；出现 `dlopen`、`pyexpat` 或 `ensurepip` 错误时，重装完整 Python 3.12 并丢弃失败的 `.venv`。

## 登录态与数据边界

- 平台登录、扫码和重新授权必须由账号本人完成。
- Cookie、浏览器 Profile、检查元数据和导出结果默认保存在当前用户的 `~/Library/Application Support/数据科学家 Community/`，不写入源码目录。
- HTTP 503、网络异常、空白或不稳定页面会记为 `unknown` 并保留上次 `authorized`；只有明确的未登录/Cookie 失效证据才提示重新授权。
- 检查不会刷新 Cookie 或承诺登录永不过期。平台页面变化、频控、安全校验和账号风控仍可能影响采集。
- 飞书同步默认不启用；只有用户完成配置并主动请求同步时，选中数据才会发送到用户自己的飞书租户。
- 社区源码模式无需许可证；14 天免费试用流程已关闭，默认也不配置商业激活、更新或反馈地址。

本项目只支持抖音、小红书、B站和快手四个平台，是独立社区项目，不是任何平台或飞书的官方产品。
